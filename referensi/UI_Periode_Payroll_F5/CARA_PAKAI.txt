UI PERIODE PAYROLL F-5

1. Ekstrak ZIP ini terlebih dahulu.
2. Buka index.html di Chrome atau Edge untuk mencoba formulir.
3. Klik + Periode baru, isi tanggal, lalu Simpan periode.
4. Klik Ubah periode, ubah tanggal pembayaran, lalu Simpan perubahan.
5. Coba menyimpan kolom kosong atau tanggal akhir sebelum tanggal mulai.
6. Batal mengembalikan tampilan tanpa menyimpan perubahan.

UNTUK FIGMA
Buka file Figma Prototype ERP Payroll, pilih halaman 01 Prototype.
Seret delapan file di folder svg ke area kosong di bawah desain lama.
Setiap SVG berukuran 1280 x 800. Susun dengan tiga layar per baris.
Gunakan sebagai acuan visual. Impor SVG tidak mempertahankan koneksi
komponen dan interaksi prototype Figma. Teks dapat menjadi outline
bergantung pada dukungan impor dan font di perangkat.

URUTAN LAYAR
01A tambah kosong, 01B tambah terisi, 01C validasi kolom wajib,
01D validasi tanggal, 01E hasil simpan, 01F edit,
01G contoh perubahan, 01H hasil simpan perubahan.

ALUR PROTOTYPE FIGMA YANG DISARANKAN
Periode baru > 01A. Simpan pada 01A > 01C.
Input tanggal > 01B. Simpan pada 01B > 01E.
Ubah periode pada 01E > 01F. Ubah tanggal pembayaran > 01G.
Simpan perubahan pada 01G > 01H. Batal > tampilan sebelum edit.
01D menjadi contoh pesan saat tanggal akhir mendahului tanggal mulai.

BATAS PROTOTYPE
Data pada HTML hanya disimpan dalam memori selama halaman dibuka.
Refresh mengembalikan data awal. Ini bukan database atau implementasi
Laravel dan tidak dapat dipakai sebagai bukti penyimpanan database.
Validasi ini adalah rancangan UI. Endpoint dan aturan backend harus
diselaraskan dengan kontrak fitur periode sebelum implementasi.
Desain menggunakan font Inter dengan fallback Arial.
